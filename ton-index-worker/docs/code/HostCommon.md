# HostCommon

Shared helpers that every protocol host binding uses to reach into block-tree data: base64 BOC cell decoding, message-body and message access, call-opcode matching, canonical account and amount Values, field reads from a block's data dict, and PTonTransfer parsing for the TON-pegged jetton. Addresses are normalized to the canonical workchain-colon-HEX upper form, with null or unparseable addresses rendered as addr_none rather than errors. All of it is stateless free functions over borrowed pointers, so there is no ownership or threading surface.
