# Цена TON в USDT — по набору Anchor pools, а не по одному захардкоженному пулу

Цену TON в USDT считаем по конфигурируемому набору из 2–4 самых глубоких USDT/TON пулов на разных DEX, со взвешиванием по ликвидности. Котируем именно в USDT, без пересчёта в USD.

Один захардкоженный адрес пула отвергнут по двум причинам. Ликвидность переезжает между версиями DEX (STON.fi v1 → v2, DeDust v1 → v2), и якорь деградирует незаметно. Кроме того, цену одного пула проще сдвинуть.
