# Собственный пайплайн цен, а не датасет ton-etl

Цены считаем сами, в нашем index worker'е. Публичный датасет ton-etl (TON Foundation: `dex_pools`, `dex_trades` на AWS Open Data) не используем как источник.

Датасет ton-etl выгружается раз в сутки, а API нужна задержка порядка секунд. Кроме того, это внешняя зависимость без SLA. Логику разбора пулов из ton-etl (`parser/parsers/accounts/tvl.py`) используем как справочник, а сам датасет — как эталон для сверки нашего бэкфилла.
