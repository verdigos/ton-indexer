# Цена — спотовая, из резервов пула, котируется в TON

Цену (Price) jetton'а считаем как Spot price из Reserves и Curve пулов, а не как Execution price свопов. Если у jetton'а несколько пулов, берём среднее, взвешенное по ликвидности. Первичный Quote asset — TON, потому что почти вся ликвидность DEX'ов на TON сосредоточена в парах X/TON. USD считаем через TON/USD (см. ADR-0002).

Execution price отвергнута: в неё входят комиссии, проскальзывание и мульти-хоп маршруты, и её нет у пулов, по которым давно не было свопов. Свопы используются только для объёма.
