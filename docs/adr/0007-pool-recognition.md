# Пул учитывается, только если его код в белом списке и он принадлежит официальному роутеру или фабрике

Контракт считаем Pool, только если выполнены два условия: code hash входит в белый список версий DEX, и пул принадлежит официальному роутеру или фабрике. Так уже устроен `DedustPoolDetector`: он сверяет пул с фабрикой. Проверка только по коду отвергнута: любой может задеплоить копию пула с поддельным роутером и выставить произвольную цену.
