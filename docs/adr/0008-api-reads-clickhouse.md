# ton-index-go читает цены напрямую из ClickHouse

Эндпоинты цен (текущие цены по списку jetton'ов; свечи с параметрами jetton, интервал, from/to, `quote=ton|usdt`) живут в `ton-index-go`, который для этого получает клиент ClickHouse. Отдельный сервис цен отвергнут: ради двух read-only эндпоинтов он добавил бы деплой и мониторинг. Цена решения в том, что API становится зависимым от ClickHouse, а не только от PostgreSQL и Kvrocks.
