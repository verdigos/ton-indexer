mch engine — a guided tutorial

commit ff4135bc · excerpts pulled from the live tree at render time · drift-checked per excerpt

A tutorial, not a reference: chapters are ordered so each one only needs what came before, and together they take you from zero to being able to read, verify, and extend the mch C++ engine. Every code block is pulled from the real tree at render time and drift-checked against the hash recorded when it was annotated — what you see IS the code. Captured-output blocks show real engine runs you can reproduce. Each chapter ends with the in-scope files that were deliberately NOT annotated (with reasons), so you always know what remains for your own reading. The ABI/tolk side gets its own tutorial later; chapter 6 previews the boundary.
